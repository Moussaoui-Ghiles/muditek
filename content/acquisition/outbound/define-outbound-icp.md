## Define the account first

An outbound ICP is a set of rules for deciding which companies belong in a campaign. It is not a list of attractive industries.

Write the rule in this order:

1. Operating situation or industry
2. Company size or commercial capacity that changes the problem
3. Geography you can serve
4. Required characteristics
5. Hard exclusions

Each rule must be observable. Replace "growing company" with the event or condition you will verify.

## Define the buyer

List who owns the problem, who controls the budget, who evaluates the solution, and who can block it. A title is evidence of a role, not proof of authority.

For every buyer role, record:

- the decision the person can make;
- the problem the role is responsible for;
- an acceptable route to that person;
- a backup role when the primary buyer is unavailable.

## Test reachability before volume

Count accounts, contacts, and messages separately. An account belongs in the reachable market only when it passes the account rules and has at least one verified path to a relevant buyer.

Document unknowns. Do not turn missing data into a positive fit decision.

## Output

The finished ICP must let two researchers approve or reject the same account using the same evidence. If it cannot, the rule is still subjective.
