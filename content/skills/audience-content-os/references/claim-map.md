## Completeness Audit

When the user asks whether the framework contains everything valuable from the chapters:

1. Check every AC ID against `references/source-doctrine.md`.
2. Check that `SKILL.md` operationalizes AC-05 through AC-23 and routes AC-24 through AC-40.
3. Verify examples and self-reported results retain their labels.
4. Verify no new mandatory stage, ratio, cadence, or outcome has been added.
5. Verify the skill can discover topics, write, audit, ask, distribute, and measure—not merely summarize.
6. Report omissions explicitly. Do not claim zero omissions unless every ID has been checked.
7. Check EX-01 through EX-10 when the user asks whether the skill contains the source examples.
