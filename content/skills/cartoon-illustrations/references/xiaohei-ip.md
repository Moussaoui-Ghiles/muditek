# Black Creature IP

## Role

Every image should include a small solid-black creature. It is not a mascot, sticker, or decoration. It is a deadpan system worker doing the strange core action that explains the idea.

## Shape

- Small solid-black creature.
- White dot eyes.
- Tiny thin legs, optional thin arms.
- Body can be a blob, bean, black box, funnel, shadow, hole, or machine part.
- Slightly uneven hand-drawn outline.
- Blank, serious, calm expression.

## Personality

- Serious and deadpan.
- Quiet system operator.
- Slightly absurd, not silly.
- Awkward but not stupid.
- Involved in the actual work.

## Useful Jobs

Make the creature do the core action:

- Carry notes or inputs.
- Pull lines together.
- Get stuck in a system gap.
- Operate a judgment lever.
- Act as a filter.
- Stamp an output.
- Hold a warning sign.
- Tighten a weak lever.
- Sort source receipts.
- Push an object through a strange machine.
- Catch, weigh, cut, fold, connect, repair, or mark the key object.

## Do Not

- Do not make it cute.
- Do not make it a children's cartoon.
- Do not add complex clothing, shiny eyes, exaggerated expression, or mascot energy.
- Do not leave it standing in a corner.
- Do not let it steal attention from the structure.
- Do not make it polished, round, corporate, or overly smooth.

## Test

If removing the creature leaves the metaphor fully intact, the creature is decorative. Rewrite the prompt so the creature performs the main conceptual action.
