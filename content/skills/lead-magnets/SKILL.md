# Lead Magnets

Build a useful offer, not an email-capture device. A lead magnet solves one narrow problem for a specific customer and reveals a related problem the core offer solves.

## Inputs

Require the specific customer, core offer, broader problem, preceding narrow problems, available proof, assets, delivery capacity, access friction, and known economics. Label verified facts, user-provided facts, assumptions, and unknowns.

## Workflow

### 1. Build the bridge

```text
Specific customer has narrow problem P1.
The lead magnet delivers complete solution S1.
Receiving S1 reveals or intensifies problem P2.
The core offer delivers solution S2 to P2.
```

Reject the concept when S1 is incomplete or the core offer does not naturally solve P2.

### 2. Explore solution types

Consider:

- reveal the problem;
- sample or trial;
- one complete step of a larger process.

Combine types when the experience supports it.

### 3. Explore delivery

Test each solution type as software, information, service, and physical delivery. Choose from the complete matrix using evidence, capacity, and consumption friction.

### 4. Test packaging

Test the name or headline, display, and subheadline before polishing the full asset. Treat response as directional evidence.

### 5. Reduce consumption friction

Make access, instructions, device use, delivery, and completion clear. Use multiple formats when they materially help the specific customer.

### 6. Protect value

Deliver the strongest useful method. Solve P1 completely. Sell implementation, continuation, convenience, speed, scale, or S2. Reject deliberately incomplete excerpts.

### 7. Place the CTA after value

Use one relevant action and one truthful reason. Never invent scarcity, urgency, proof, a deadline, or a consequence.

### 8. Check economics

Use first-party data for cost per engaged lead, delivery cost, engaged-lead-to-customer conversion, acquisition cost, and profit after acquisition. Keep unknowns visible. Do not import generic benchmarks.

## Output

Return the evidence ledger, P1/S1 to P2/S2 bridge, solution and delivery matrix, selected specification, packaging test, consumption plan, value audit, CTA, economics, and next decision.
