# Caption prompt

```text
Write one caption for the completed TikTok slideshow.

Inputs:
- final slide copy;
- content ledger;
- source links;
- approved CTA;
- current manually researched hashtags, if supplied.

Requirements:
- add context, attribution, or a useful limitation;
- do not repeat the first-slide hook;
- do not add a claim that is absent from the slides and source ledger;
- use one CTA only;
- include hashtags only when the user supplied or approved them;
- keep the language plain and specific.

Return the caption only.
```
