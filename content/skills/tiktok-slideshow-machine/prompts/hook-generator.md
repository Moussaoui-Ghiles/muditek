# Hook prompt

Use after the content ledger is complete.

```text
Write five first-slide hooks for this TikTok slideshow.

The hook must:
- name the concrete subject;
- state one true reason to swipe;
- use only facts in the supplied ledger;
- create a promise the remaining slides fully deliver;
- remain readable in no more than four short lines.

Do not add a number, test, result, deadline, enemy, or first-person claim.
Do not score the options.

Return the five hooks, then recommend one with a one-sentence reason tied to the source and slide plan.
```

Reject a hook when it could introduce any topic, hides the subject, or needs later slides to repair an unsupported promise.
