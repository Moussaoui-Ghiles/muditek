# Copy and visual constraints

Reject copy that uses:

- unsupported superlatives;
- “game-changer,” “revolutionary,” “must-have,” “unlock,” or “10x” without evidence;
- “most people,” “nobody,” or “everyone” without evidence;
- generic introductions such as “let's dive in”;
- fabricated tests, quotations, user counts, savings, rankings, or deadlines;
- several clipped fragments that obscure meaning;
- more than one CTA.

Reject visuals that use:

- fake product interfaces;
- generated logos or brand marks;
- text baked into generated images;
- stock imagery that does not support the point;
- low-contrast text;
- decoration that competes with the content;
- unlicensed media.

A source reference may justify a different layout choice. It never justifies copying unsupported claims.
