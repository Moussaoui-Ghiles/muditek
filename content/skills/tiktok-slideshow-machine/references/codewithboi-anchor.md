# Two-slide editorial reference

Use this file as a layout reference, not as proof that a new post will perform.

The bundled template demonstrates a compact two-slide format:

1. **Hook slide:** one specific promise, one line of context, and a clear swipe cue.
2. **Payoff slide:** a visual hierarchy that delivers the promised categories or ranking.

## Visual system

- Canvas: 1080 x 1920.
- Safe area: at least 72 pixels on every edge.
- Background: warm off-white.
- Text: near-black with one rust accent.
- Display type: high-contrast serif.
- Body type: plain sans serif.
- Labels: mono or narrow sans serif.
- Decorative elements: one short rule and restrained borders.

## Hook slide

The first slide must state:

- the concrete subject;
- the promised number, comparison, or result when verified;
- enough context to understand what the next slide will deliver.

Do not use a number simply because the reference did. The number must come from the new source set.

## Payoff slide

The second slide must fulfil the first slide's promise. Use a hierarchy only when the items have a real ordering rule. Name that rule in plain language.

If the source supports categories but not rank, use grouped columns or rows instead of a pyramid.

## Reuse boundary

Reuse the layout logic and spacing. Replace the brand, content, dates, CTA, categories, and evidence. Do not copy another creator's metrics or present the reference as a guarantee.
