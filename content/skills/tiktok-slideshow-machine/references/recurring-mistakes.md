# Visual QA and recurring mistakes

Check the rendered PNG files, not only the HTML.

## Content

- The hook hides the subject behind vague language.
- The first slide promises a number or comparison the set does not deliver.
- A ranking has no stated ranking rule.
- Another creator's result is presented as first-party proof.
- The caption adds an unsupported claim.
- The final slide asks for several actions.

## Layout

- Text touches the safe area.
- A line ends with an orphaned word.
- Small labels become unreadable on a phone.
- A logo or image is stretched, blurry, or missing.
- Decorative elements compete with the information.
- Visual hierarchy changes between slides without a reason.
- The final image is not 1080 x 1920.

## Process

- The format was recreated from memory instead of complete screenshots.
- Source URLs or capture dates are missing.
- The operator approved HTML without opening the PNG files.
- A paid API or model was added to a local rendering task.
- Posting was automated without explicit authorization.

## Final pass

- [ ] Complete source captured.
- [ ] Claims trace to evidence.
- [ ] Every bracketed placeholder replaced.
- [ ] All output images opened and reviewed.
- [ ] Phone-size preview is readable.
- [ ] One CTA follows the payoff.
- [ ] Posting remains manual.
